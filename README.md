# 🖥️ ShaneCodes Inventory — Laptop Management System

![Version](https://img.shields.io/badge/version-2.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Status](https://img.shields.io/badge/status-stable-brightgreen)

A powerful, modern laptop inventory management system built for repair shops, IT departments, and computer technicians. Track laptops by model, specs, issues, missing parts, and repair progress — all with real-time cloud sync.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 📊 **Dashboard** | Real-time stats: total laptops, in-progress, completed, missing parts, average days |
| 🔧 **Full CRUD** | Add, Edit, Delete laptop entries with ease |
| 🔍 **Search & Filter** | Search by model, serial, or issue. Filter by status |
| 🧩 **Parts Tracker** | Auto-count missing parts (LCD, Frame, Battery, Keyboard, Other) |
| ☁️ **Cloud Sync** | Sync data to Google Sheets via Sheet.best (no auth needed!) |
| 📥 **CSV Export** | One-click export reports for management |
| 🌓 **Dark/Light Theme** | Toggle between dark and light modes |
| 📱 **Mobile Responsive** | Works on desktop, tablet, and phone |
| 👥 **Multi-User** | Share the URL with your entire team |
